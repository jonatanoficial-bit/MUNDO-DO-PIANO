Mundo do Piano - v0.9.2_20260428_2044

Este pacote corrige os caminhos internos do app, mas NÃO inclui os PDFs pesados.

Como usar:
1. Descompacte este ZIP.
2. Copie os arquivos por cima do seu projeto local.
3. NÃO apague os PDFs que já estão no GitHub.
4. Rode:
   git add .
   git commit -m "Corrigir app sem reenviar PDFs"
   git push

Observação:
A pasta lessons/ neste pacote contém apenas arquivos .txt de orientação.
Se você copiar por cima manualmente, não substitua seus PDFs reais por essa pasta vazia.
O ideal é copiar apenas:
- index.html
- data/
- config/
- admin/
